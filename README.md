# Arduino-Pandora
Progressive Automated Nonmetal & Durable Object Recycling Assistant 

Components in used:
- Arduino Uno R3
- Ultrasonic Sensor (SRF05)
- Inductive Proximity Sensor
- Microservo Sg90

Mechanism:
- Detect items in
- Detect inductivity
- Angle made based on metal or non-metal material
- Item sorted
