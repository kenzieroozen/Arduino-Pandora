# Arduino-Pandora
Progressive Automated Nonmetal & Durable Object Recycling Assistant 

Components used:
- Arduino Uno R3
- Ultrasonic Sensor (SRF05)
- Inductive Proximity Sensor
- Microservo Sg90

Mechanism:
- Detect item in
- Detect inductivity (metal or non-metal)
- Angle made by servo
- Item sorted
